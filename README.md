# Мой ритм

Мобильный личный дневник: лекарства, вес, давление и пульс, шаги, самочувствие, дневник Редуксина и питание.

Данные сохраняются локально в браузере пользователя. В репозитории нет персональных записей.

## Питание

Голосовой и ручной ввод умеют рассчитывать примерную калорийность и БЖУ для распространённых продуктов по указанным граммам. Фото-анализ сложных блюд требует отдельного защищённого AI-бэкенда и не хранит API-ключ в публичном коде GitHub Pages.

> Расчёты калорийности приблизительные и зависят от состава блюда, способа приготовления и точности массы порции.
